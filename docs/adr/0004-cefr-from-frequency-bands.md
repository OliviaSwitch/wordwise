# CEFR levels mapped from frequency rank bands

Proficiency levels use the CEFR scale (A1–C2) mapped from corpus frequency rank bands: A1≤1000, A2≤2000, B1≤4000, B2≤8000, C1≤14000, C2≤24000. These cutoffs are adopted from Readest's `difficulty.ts` and are an approximation — true per-word CEFR classification would require the English Vocabulary Profile dataset, which has licensing restrictions.

The cutoffs can be tuned later without changing the data format; they are a runtime constant, not baked into the Gloss Pack.
